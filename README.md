# Retail Customer Behavior & Shopping Trends Analysis

An end-to-end data analytics project that explores retail customer behavior and shopping trends using **Python**, **SQL**, and **Power BI**.

## Overview

This project takes a raw retail customer dataset through the full analytics workflow: cleaning and exploring the data in Python, answering business questions with SQL, and presenting the results in an interactive Power BI dashboard.

**Goal:** Understand how different customer groups shop and what drives purchasing behavior, so a retail business can make better decisions about products, marketing, and promotions.

## Tools Used

| Area | Tools |
|------|-------|
| Data cleaning & exploration | Python (Pandas, NumPy) |
| Analysis | SQL |
| Visualization | Power BI |
| Version control | Git, GitHub |

## Dataset

A retail customer behavior and shopping trends dataset containing customer demographics and purchase details.

## Business Questions

1. Which product categories generate the most revenue?
2. How does spending differ across customer age groups and genders?
3. Which seasons, locations, or payment methods show the strongest sales?
4. Do discounts, subscriptions, or repeat purchases change customer behavior?

## Project Workflow

### 1. Data Cleaning & Exploration (Python)
- Loaded the dataset with Pandas
- Checked for missing values, duplicates, and incorrect data types
- Standardized column names and cleaned inconsistent values
- Explored distributions and summary statistics

### 2. SQL Analysis
- Loaded the cleaned data into a database
- Wrote SQL queries to answer the business questions above

### 3. Dashboard (Power BI)
- Built an interactive dashboard to present the main trends and insights
